## Como este blog funciona

Cada artigo é um arquivo de texto simples (Markdown) dentro da pasta `content/articles/`. Para publicar um novo artigo:

1. Crie um novo arquivo `.md` nessa pasta (pode copiar este como modelo).
2. Preencha o cabeçalho no topo do arquivo (entre as linhas `---`) com título, data, categoria e um resumo.
3. Escreva o conteúdo do artigo em Markdown normalmente abaixo do cabeçalho.
4. Salve e envie (`commit`) o arquivo para o repositório no GitHub.

Assim que o arquivo é enviado, o site é atualizado automaticamente — sem precisar mexer em código, banco de dados ou instalar nada.

## Por que Markdown?

Markdown é só texto com uma formatação simples: `**negrito**`, `_itálico_`, `## título`, listas com `-`, links `[texto](url)`, etc. É leve, funciona em qualquer editor (inclusive direto pelo site do GitHub, no navegador do iPad) e fica guardado com histórico de versões.
